To-Do Manager

About

A simple task management application for organizing daily activities.

Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser localStorage
- Responsive interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Add, complete, or delete tasks.

Project Purpose

To practice JavaScript events, DOM manipulation, and browser data storage.
